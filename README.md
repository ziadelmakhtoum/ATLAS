ATLAS
ATLAS est une plateforme intelligente de recherche et d'exploration de voyages.

Le projet vise à aider les voyageurs à :

comparer les vols ;
découvrir des destinations et territoires souvent invisibles sur les comparateurs classiques ;
comprendre les formalités administratives selon leur nationalité ;
explorer les possibilités de déplacement à travers le monde.
Projet en cours de développement. Fondateur : Ziad El Makhtoum.
